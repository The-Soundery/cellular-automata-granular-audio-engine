Observation: exclusive order Osc → Calm → Flow → leftover split by δ into
  Chaos (changing) or Texture (still, no body; code alias textured). Calm =
  connected similar colour + κ (fill is not a membership gate). Flow =
  similarity travel (correspondence / hop), punched out of chaos remainder,
  not out of calm. Persist (sliding body) → Calm; hop (colour leaves and
  lands nearby) → Flow. Solid never-changing colour is Calm; frozen mixed
  detail is Texture. Speckles that pass κ + colour-join but fail
  minRegionArea stay silent — not promoted into Texture. Chaos bag is
  partitioned into connected chaotic areas (ChaosCluster, Chebyshev join;
  small fragments → one residual scatter entry) — spatial measurements with
  COM-matched ids for rate-clock phase, never owners.
  Region id matching / velocity ignore torus-degenerate COM axes
  (regionComResultantMin — absolute circular resultant, NOT conc-relative:
  a full-height mass has float-noise COM; a near-wrapping strip does not).
  Without this a stable wrapping region churns ids every few steps.
  Calm lifecycle (births / deaths / merges) exported as regionEvents.
Scheduler: five pools (calm / texture / chaos / osc / flow); area-share
  concurrency; every confirmed calm / flow / osc / texture colour group gets
  at least one seat (area-ranked via largest remainder if guaranteed seats
  overflow); chaos spent per chaotic area (sub-share ∝ area, rate ∝ own δ̄,
  duration from own bag stats; residual bag included; global share + budget
  still the ceilings; compact ChaosCluster AABB height → Q like calm,
  residual scatter stays one-row); flow piece-spawn + FLOW_ID_BASE tracks;
  texture colour groups use TEXTURE_ID_BASE (hue×island spatial ids);
  timeOrder→dur/env, shape extent→Q (needles blend AABB height toward
  minor-axis thickness; filled slabs keep height; compactness blends
  duration/brokenness with fillRatio; Q follows live qExtent on
  calm/flow tracks, window frozen); meanSimilarity→read-offset spread;
  chaos spawn biased toward cluster COM; directionFromHeading (full vel);
  stratified+dispersion sites (calm/texture groups); SPAWN_ANCHOR_R_MIN;
  no inter-grain scrub clock; CHAOS_EVENTS_MAX_HZ CPU rail only;
  HSV→polar material query absolute (segment startPos/endPos = window;
  loop tightness may shrink ping-pong inside that window);
  scale layer from structure area / broken-up-ness (default native;
  chaos occupancy floor);
  calm/texture read past onset inside the window; silence never selectable
  (energetic hops only; windows stay in contiguous audible runs).
  Periods in steps convert to seconds with the measured step interval
  (stepSec EMA; HUD RATE row) — not the nominal 30 (display-quantised CA
  rarely runs at 30 and osc pitch must lock to the visual period).
  Region births fire their first grain the step they appear (rhythm
  path included when the seat is empty); merged-away ids keep alias
  tracks at the survivor's anchor while their grains live, count against
  that survivor's share, and donate packing credit to the survivor
  clock. Dead-id grains short-release on death; over-share grains
  yield seats (worklet forceShortRelease by grainId — bake envelope first)
  so a newly allocated pool can spend; flow occupancy is live `active`
  only (do not add events — that halved fill). Calm follow is velX/velY
  conveyor + CALM_FOLLOW_CORR_CAP, not raw COM. Calm attack is fraction
  law capped by ATT_ABS_MAX_S; under-seat catch-up fills in ~CALM_FILL_S
  (skip when shrinking hard; empty seated calm/non-pulsed flow force one
  grain if the budget has room). Non-pulsed flow catch-up uses FLOW_FILL_S.
Renderer RMS (scripts/render-scenarios.mjs): primary = sqrt(mean(L²+R²));
  mono 0.5*(L+R) reported secondary only.
