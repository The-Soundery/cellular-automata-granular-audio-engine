Live pipeline
------------------------------------------------------------------------------

Utomata (or TestPatterns) → FrameObserver (cold-start primes both buffers)
  → FieldObserver → GrainScheduler → AudioEngine.sendEvents (+ track)
  → grain-processor (polar HSV window; stereo L/R by channelMix;
                     absolute Y bandpass 80 Hz–12 kHz; bandwidth-compensated;
                     envNorm after attack/release rescale; equal-power pan;
                     direct pan/Y/channelMix follow with one-block param ramp)

Observation: exclusive order Osc → Calm → Flow → leftover split by δ into
  Chaos (changing) or Static (still; code alias textured). Calm = connected
  similar colour + κ (fill is not a membership gate). Flow = similarity
  travel (correspondence / hop), punched out of chaos remainder, not out of
  calm. Persist (sliding body) → Calm; hop (colour leaves and lands nearby)
  → Flow. Solid never-changing colour is Calm; frozen mixed detail is Static.
  Chaos bag is partitioned into connected chaotic areas (ChaosCluster,
  Chebyshev join; small fragments → one residual scatter entry) — spatial
  measurements with COM-matched ids for rate-clock phase, never owners.
  Region id matching / velocity ignore torus-degenerate COM axes
  (regionComResultantMin — absolute circular resultant, NOT conc-relative:
  a full-height mass has float-noise COM; a near-wrapping strip does not).
  Without this a stable wrapping region churns ids every few steps.
  Calm lifecycle (births / deaths / merges) exported as regionEvents.
Scheduler: five pools (calm / texture(=static) / chaos / osc / flow); area-share
  concurrency; calm gets flow's ¼-seat floor (exact ≥ 0.25 → 1 voice);
  if those floors overflow the budget, re-apportion by largest remainder
  on exact area (do not floor(1×scale) → 0);
  chaos spent per chaotic area (sub-share ∝ area, rate ∝ own δ̄, duration
  from own bag stats; residual bag included; global share + budget still
  the ceilings); flow piece-spawn + FLOW_ID_BASE tracks; split material
  (timeOrder→dur/env, spectralT→Q); stratified+dispersion sites (calm/texture);
  SPAWN_ANCHOR_R_MIN; scrub clocks; CHAOS_EVENTS_MAX_HZ CPU rail only;
  HSV→polar material query (mel-PCA angle/band from offline prep);
  calm/texture restricted to sustained subset; silence never selectable.
  Periods in steps convert to seconds with the measured step interval
  (stepSec EMA; HUD RATE row) — not the nominal 30 (display-quantised CA
  rarely runs at 30 and osc pitch must lock to the visual period).
  Region births fire their first grain the step they appear; merged-away
  ids keep alias tracks at the survivor's anchor while their grains live
  and count against that survivor's share. Dead-id and over-share grains
  yield seats (worklet forceShortRelease by grainId — bake envelope first)
  so a newly allocated pool can spend; flow occupancy is live `active`
  only (do not add events — that halved fill). Calm follow is velX/velY
  conveyor + CALM_FOLLOW_CORR_CAP, not raw COM.
Renderer RMS (scripts/render-scenarios.mjs): primary = sqrt(mean(L²+R²));
  mono 0.5*(L+R) reported secondary only.
